# Iconos Fluent locales

Origen: https://github.com/microsoft/fluentui-system-icons (Microsoft, licencia MIT).
Descargados el 2026-08-16 desde `raw.githubusercontent.com`, rama `main`, uno por uno.
No se clonó el repositorio completo ni se ejecutó Git dentro del repositorio CRM.

## Tratamiento aplicado

- `fill`/`stroke` con color fijo sustituidos por `currentColor`.
- `width`/`height` retirados: el tamaño lo fija el CSS.
- Los símbolos se sirven desde un sprite EN LÍNEA dentro del HTML, no por CDN
  ni por petición externa: no existe ninguna solicitud de red para iconos.
- Los `.svg` originales permanecen en esta carpeta como fuente y evidencia.
